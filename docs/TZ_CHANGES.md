# Уточнения примерного технического задания

Пользователь разрешил менять примерное ТЗ для эффективности. Ниже решения
стартовой версии; исходный документ сохранён неизменённым в references.
Это не протокол успешной приёмки и не утверждение о достигнутом качестве.

| Пункт | Принятое уточнение | Причина и проверка |
|---|---|---|
| Название классов ОС | Визуальный тип iPhone / Android-смартфон | Установленная ОС по корпусу не проверяется |
| Базовая модель | Визуальный энкодер MobileCLIP2-S0 с линейной головой | Перенос обучения на небольшую выборку; качество проверяется test |
| D-01 JPEG RGB | JPEG и PNG, поддерживаемые 8-битные режимы приводятся к RGB | Удобство сбора; преобразование одинаково в train/inference |
| D-02 640×480 | Короткая сторона≥480, длинная≥640, любая сторона≤6000 | Явно разрешена портретная ориентация |
| D-03 размер и число объектов | Ручной контроль одного крупного телефона | Автоматического детектора в версии 0.1.0 нет |
| D-04 пропорции | Letterbox 256×256 с bilinear | Телефон сохраняется целиком; покрыто тестом пропорций |
| Уверенность | Некалиброванная оценка softmax, порог предупреждения 0,60 | Не называем гарантированной вероятностью правильности |
| F-04 низкая уверенность | Класс и предупреждение; ошибки этих ответов учитываются в метриках | Нельзя улучшать accuracy исключением неудобных кадров |
| Формат модели | visual.safetensors + base.json и head.npz + run.json | Разделение базы/головы, загрузка без pickle, контроль хешей |
| Данные test≥200 | Цель сохранена, размеры контролируются после группового разбиения | При 600 всего ориентир 320/80/200; фактические группы могут изменить числа |
| Разработка и обучение | До 4–8 ГБ свободного места для окружения, CUDA по выбору | Исходные 2 ГБ на всё могут быть недостаточны для PyTorch |
| Размер готовой поставки≤1,5 ГБ | Требование пока не подтверждено | Нужны упаковка CPU-runtime и измерение; исходный ZIP его не доказывает |
| Скорость≤2 с и память≤2 ГБ | Сохранены как цели приёмки | Измеряются benchmark на целевом ПК после обучения |

Неизменны: локальность штатной работы, сохранность фотографий, отдельное
обучение, однократная загрузка модели в сеансе, русские сообщения, журнал,
версии и отдельный итоговый test.
