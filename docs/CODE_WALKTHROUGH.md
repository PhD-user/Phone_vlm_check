# Как читать исходный код

Начните с cli.py: parser задаёт команды, execute связывает команду с модулем.
Тяжёлые импорты выполняются внутри нужной ветки, поэтому --help не загружает
нейросеть. Ошибки ожидаемых ситуаций оформлены как ProjectError; --debug перед
командой добавляет traceback для разработчика.

В images.py важны read_rgb и preprocess. Первая проверяет заголовок, размер,
формат и режим до декодирования, учитывает EXIF и возвращает отдельную RGB-копию.
Вторая сохраняет пропорции через letterbox, масштабирует значения и переставляет
оси HWC→CHW, как ожидает PyTorch. Обе функции общие для train и inference.

В dataset.py функция groups использует union-find: если a связан с b устройством,
а b с c сессией, все три входят в одну компоненту. split_dataset распределяет
целые компоненты, подбирая близкие размеры частей без обращения к метрикам
модели. assert_no_leakage повторно проверяет этот инвариант перед обучением.
audit считает точный SHA-256 и приблизительный dHash. Визуально похожие пары
нужно просматривать: автоматическая эвристика не знает историю съёмки.

В download.py зафиксированы источник, ревизия и SHA-256 полного checkpoint.
Из него сохраняются только визуальные тензоры. make_visual в backbone.py
создаёт ту же архитектуру через timm. load_state_dict(strict=True) запрещает
молчаливую загрузку случайно другой модели. pretrained=False и локальный
load_file исключают автоматическое скачивание при распознавании.

Extractor.eval и requires_grad_(False) замораживают BatchNorm/веса. Вызов
inference_mode не строит граф градиентов, экономя память. Признаки нормируются
по L2; одну и ту же нормировку получает голова при обучении и применении.

В features.py feature_contract связывает кэш с фотографиями, метками, split,
предобработкой и базой. Если меняется хотя бы один элемент, train/evaluate
отказываются использовать старый кэш. Это защита воспроизводимости, а не
механизм защиты от намеренной подделки JSON.

В training.py ключевые строки — маски train_mask/val_mask и fit только по
train_mask. Test не участвует в выборе параметра C. Экспорт преобразует один
бинарный logit sklearn в два эквивалентных logit softmax и проверяет совпадение
вероятностей. Голова хранится обычными массивами NPZ, без joblib/pickle.

В inference.py Recognizer загружается один раз, predict обрабатывает одну
фотографию, append_log сохраняет результат. Низкая уверенность добавляет
предупреждение, но не превращает ошибку классификации в исключённый пример.
evaluation.py считает основные метрики по всем кадрам выбранной части.

В gui.py рабочий поток отвечает за нейросеть, основной — за Tkinter. Очереди
сообщений не дают рабочему потоку менять виджеты напрямую. Новые функции
интерфейса лучше добавлять через те же очереди. Параллельные сеансы в один
журнал и управление несколькими моделями здесь не реализованы.

tests/test_core.py проверяет пропорции, EXIF, ошибки ввода, утечки и метрики.
tests/test_workflow.py выполняет настоящий визуальный энкодер на искусственных
картинках с заблокированной сетью. Затем меняет только test-метки и проверяет,
что выбранный C и обученные веса не изменились. Это проверка разделения данных,
а не оценка распознавания телефонов.
