# Применение обученной системы

## Перед первым запуском

Установите окружение по README. Убедитесь, что доступны models/base и папка
обученного эксперимента с run.json и head.npz. В стартовой поставке базовый
энкодер есть, а голова на ваших телефонах ещё не обучена.

## Одна фотография

```bash
python -m phone_vlm predict "C:/photos/phone.jpg" --run runs/experiment_001
```

Можно указать абсолютный путь; исходник останется без изменений. В ответе:

| Поле | Значение |
|---|---|
| status | ok — ответ без предупреждений; warning — ответ с предупреждениями; error — обработки нет |
| class | android или iphone; при технической ошибке null |
| answer | Человекочитаемое обозначение класса |
| confidence | Оценка softmax от 0 до 1 |
| low_confidence | Оценка ниже порога сохранённого эксперимента |
| warnings | Предупреждения об уверенности, яркости или однотонности |
| model_version | Имя папки обученного эксперимента |
| elapsed_seconds | Время обработки без однократной загрузки модели |

Вывод вероятностей не подтверждает правильность ответа. При низкой уверенности
повторите съёмку, проверьте ракурс и читаемость признаков, при необходимости
проверьте телефон вручную. Отсутствие предупреждений не гарантирует правильность.

## Папка

```bash
python -m phone_vlm batch "C:/photos" --output reports/batch_001.csv
```

Обрабатываются все обычные файлы непосредственно в папке, без вложенных папок.
Текстовый или повреждённый файл получит строку с ошибкой. CSV и журнал должны
находиться вне папки входов. Существующий выходной CSV не перезаписывается.

## Окно приложения

```bash
python -m phone_vlm gui --run runs/experiment_001
```

Дождитесь сообщения о загрузке модели, выберите фотографию, нажмите «Распознать».
После ответа можно выбрать другую фотографию. Энкодер остаётся загруженным.
В окне нет кнопки обучения. На Linux при отсутствии Tkinter установите пакет
Tk для используемого Python через менеджер пакетов ОС; для окна нужна графическая сессия.

## Журнал и настройки

Журнал по умолчанию `reports/predictions.jsonl`, UTF-8: одна JSON-запись на
обработку. Содержит время UTC, имя файла, статус, класс, оценку, версию и время
обработки. Пиксели и полные пути не сохраняются. Имя файла тоже может содержать
личные сведения — выбирайте нейтральные имена при передаче результатов.

Порог 0,60 фиксируется в run.json при обучении. Изменение training в текущем
config не меняет уже обученный run. Для нового порога создайте новую версию
эксперимента с соответствующей конфигурацией и повторите оценку. Не редактируйте
зафиксированную приёмочную версию задним числом.

## Типичные ошибки

| Сообщение или ситуация | Действие |
|---|---|
| Нет run.json | Сначала выполните train или укажите существующий --run |
| Нет visual.safetensors | Восстановите models/base из архива или выполните download с сетью |
| Контрольная сумма не совпадает | Верните зафиксированную версию файла; не отключайте проверку |
| CUDA недоступна | Укажите --device cpu или проверьте драйвер и CUDA-сборку PyTorch |
| Не установлена зависимость | Используйте Python из .venv, выполните установку requirements |
| Недостаточное разрешение | Используйте исходный более подробный снимок без искусственного растяжения |
| Кэш не соответствует данным | Создайте новый кэш после фиксации новой разметки и разбиения |

В штатных командах распознавания сеть не нужна. Команда download и установка
зависимостей — отдельные подготовительные действия, требующие интернета.
