# Проверка стартовой поставки

Проверка выполнялась на Linux x86-64, Python 3.12.14, PyTorch 2.8.0+cpu,
torchvision 0.23.0+cpu. Полные версии записаны в
`requirements-verified-linux-cpu.txt` и `validation/verification.json`.

## Что проверено

- Импорт и компиляция исходников, справка команд, doctor, pip check.
- Загрузка исходного safetensors с совпадением зафиксированного SHA-256,
  извлечение визуальных весов и строгая совместимость слоёв.
- Численное сравнение визуального энкодера с OpenCLIP 3.2.0, загруженным полным
  тем же checkpoint. На одном искусственном RGB-изображении при одинаковой
  предобработке максимальное абсолютное расхождение 0.0. Это проверка эквивалентности
  реализации на данном входе, не доказательство качества на смартфонах.
- Автоматические проверки пропорций, EXIF, сохранности источников, неверных
  входов, конфликтов разметки, транзитивных групп и утечки между частями.
- Полный цикл на искусственных изображениях через настоящие базовые веса:
  audit, split, extract, train, evaluate, predict, batch, журнал и benchmark.
  Сеть в этом интеграционном тесте запрещена.
- Изменение только тестовых меток не меняет выбранный C и веса головы.
  Изменение исходной фотографии делает прежний кэш недействительным.
- Отсутствующая обученная голова даёт понятную диагностику CLI.
- Синтаксис Linux-скрипта установки и целостность собранного ZIP.

Итоговый результат тестового запуска смотрите в `validation/unit_tests.txt` и
`validation/verification.json`. При последующих изменениях эти файлы являются
снимком поставки, а не автоматически обновляющимся статусом проекта.

## Что не проверено

Реальные фотографии iPhone/Android не предоставлены, поэтому телефонный
классификатор не обучен, итоговая accuracy/recall неизвестны. Нет подтверждения
целевых метрик, скорости и памяти на пользовательском ПК. Windows PowerShell,
CUDA и интерактивное окно Tkinter на целевом Windows-ПК не тестировались.
Tkinter-модуль доступен в проверочном окружении, но графический экран отсутствует.

Искусственные изображения в тестах служат только проверке программы и не
включены в train/test телефонов. Их временные головы удаляются после теста.
В runs стартовой поставки нет выдаваемой за готовую обученной телефонной модели.
